# Runtime spec-shape violations the AWS simulator is allowed to report.
#
# Format: op<TAB>kind<TAB>field, with array indices collapsed to []. Consumed by
# scripts/check-spec-violations.sh, which fails on any violation NOT listed
# here. Every entry carries a BUG ID and the list only shrinks — a new
# divergence is a failure, never an addition.
#
# The list is empty, and an entry is close to always the wrong answer for a
# shape whose declared pattern is stricter than the service it describes:
# allowlisting the field stops the value being checked at all. Such a shape
# takes a correction in specs/cloud-api/aws/<model>.supplement.json, which
# records the evidence, pins the upstream text it replaces, and keeps the member
# validated against what AWS really returns.
